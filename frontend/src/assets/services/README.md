# Apache service logos

Local copies are bundled so the CML application does not depend on external
network access at runtime.

- `apache-atlas.svg`: Apache Atlas repository,
  `dashboard/public/img/apache-atlas-logo.svg`.
- `apache-hive.svg`: Apache Hive website, `/images/hive.svg`.
- `apache-hadoop.png`: Apache Hadoop repository,
  `hadoop-yarn-ui/src/main/webapp/public/assets/images/hadoop_logo.png`.
